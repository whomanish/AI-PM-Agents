# Product Release Doc Writer — support

For installation problems, package defects or documentation feedback, [open an issue in AI-PM-Agents](https://github.com/whomanish/AI-PM-Agents/issues/new).

Include the tool name, package version, application, the relevant setting or installation route, and a short description of the issue. A small fictional example is useful when reporting a drafting problem.

GitHub issues are public. Do not include confidential release information, personal data, access credentials or private conversation transcripts. Remove sensitive information from screenshots before posting.

This is a community-maintained open-source tool; no response-time commitment is made. For account access, identity verification or marketplace review status, use the support channels provided by the relevant application or platform.

See [privacy information](privacy.md) for the package's data practices.
