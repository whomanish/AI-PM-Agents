# AI PM Agents

Open-source PM skills and agents for useful, reviewable product work.

## Tools

| Tool | Type | What it does |
|---|---|---|
| [Product Release Doc Writer](product-release-doc-writer/) | Agent Skill | Drafts or revises internal and external release notes, product release plans, feature FAQs and support FAQs from supplied evidence. |

Each tool has its own folder with usage documentation, installation instructions and download links. New tools can be added alongside existing ones and released independently.

## Product Release Doc Writer

Start with the [tool overview and downloads](product-release-doc-writer/README.md). It includes a portable skill ZIP for Claude and local Codex/Claude Code use, and an OpenAI plugin ZIP for ChatGPT environments with plugin support.

The instructions are provider-neutral. Host application features and permissions determine available installation routes; application loading and triggering have not been verified across every environment.
